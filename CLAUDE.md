# maps-agent

Go agent that serves Falcon BMS mission/flight data to the Interactive Maps app (see README.md).

- Builds without cgo; cross-compile from Linux with `make` (→ `bin/maps-agent.exe`)
  (the agent also runs in Wine/Proton next to BMS).
- Tests run natively on Linux: `go test ./...`

## Updating Falcon BMS shared memory (`include/FlightData.h`)

When `include/FlightData.h` was updated or the shared memory port in `bms/` is touched, **read
`bms/CLAUDE.md` first**. It contains the workflow, the C++→Go type mapping and the pitfalls.
The Go structs must match the header's memory layout byte for byte; `go test ./bms` checks this
against `bms/testdata/layout.txt`, which is generated by `python3 bms/testdata/gen_layout.py`.
